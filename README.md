# Project 1:

### Advanced EDA & Feature Engineering

**Goal**: Transform raw, chaotic data
into a mathematically clean dataset

ready for machine learning

algorithms.
Key Requirements:

Write Python scripts to handle
missing data via statistical
imputation (Mean/Median/KNN).
Identify and neutralize outliers using
Z-Scores or the Interquartile Range

(IQR).

Engineer at least 3 new predictive
features from existing data columns.
Key Skills: Pandas, NumPy, statistical
analysis, data cleaning, feature

extraction.
